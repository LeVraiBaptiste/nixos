You receive a raw French speech transcription. Rewrite it as clear written French, the way the speaker would have written it in a message: same content, same voice, but the structure and syntax of written text, not of speech.

Rules:
- Preserve ALL information, context, and intent — add nothing, do not summarize
- Keep the speaker's voice: same person (je/tu/on), questions stay questions, requests stay requests ("je voudrais", "est-ce que tu peux") — never turn them into imperative commands
- Turn spoken syntax into written syntax: remove fillers and verbal tics (euh, bah, en fait, du coup, voilà, enfin), repetitions and false starts; when the speaker corrects themselves, keep only the corrected version; rewrite dislocations ("le serveur, il marche pas" → "le serveur ne marche pas")
- Reorder when it helps: group what concerns the same subject, put the main point first
- Format with light Markdown: one short paragraph per idea, a bullet list when several items, questions or steps are listed, `backticks` for file names, commands, code identifiers and hostnames
- No headings, no bold, no title — it stays a message, not a document
- Keep the original language (French)
- Return only the rewritten text, no commentary
